**VeloShop** — это полнофункциональное мобильное приложение интернет-магазина велосипедов, написанное на современном стеке Android-разработки. Приложение спроектировано с учетом реальных бизнес-процессов и поддерживает разделение ролей (Клиент, Менеджер, Администратор).

## 📱 О проекте

Приложение работает полностью автономно. В качестве базы данных используется локальное хранилище (`SharedPreferences` + JSON), что позволяет запустить проект и протестировать весь флоу без необходимости развертывания серверной части.

### 🌟 Ключевые возможности

#### Для Клиента:
*   **Умная регистрация и вход:** Защита от ботов с помощью кастомной **Grid-капчи (Emoji)**. Двухфакторная аутентификация (имитация OTP-кода через Push-уведомления).
*   **Каталог:** Поиск с дебаунсом, фильтрация по категориям, сортировка по цене/названию, пагинация (загрузка по 20 элементов) и красивый **Skeleton Loading** при загрузке.
*   **Избранное:** Добавление товаров в вишлист (сердечко) с отдельным экраном.
*   **Карточка товара:** Поддержка **Shared Element Transition** (анимация перелета картинки из каталога). Система отзывов и оценок (пользователь может оставить только один отзыв на товар, средний рейтинг пересчитывается автоматически).
*   **Умный подбор (FitFinder):** Интерактивный опрос для подбора идеального велосипеда по бюджету и стилю катания.
*   **Корзина и оформление:** Выбор конкретных товаров, изменение количества, **применение промокодов** (скидка высчитывается автоматически), выбор способа оплаты (карта/наличные) и доставки (курьер/самовывоз).
*   **Профиль:** История заказов с трекером статусов, личные заметки, смена темы (Светлая/Темная/Системная).

#### Для Менеджера и Администратора:
*   **Управление товарами (CRUD):** Добавление, редактирование и удаление велосипедов. 
*   **Импорт из CSV:** Загрузка каталога из файла с **умной защитой от дубликатов** (проверка по названию и бренду, регистронезависимость).
*   **Управление заказами:** Просмотр всех заказов пользователей и изменение их статусов.
*   **Управление акциями:** Создание промокодов и баннеров, которые сразу видны клиентам.
*   **Управление пользователями (только Админ):** Назначение ролей, блокировка/удаление аккаунтов.

## 🛠 Технологический стек и Архитектура

*   **Язык:** Kotlin
*   **UI Framework:** Jetpack Compose (Material 3, анимации, кастомные компоненты)
*   **Архитектурный паттерн:** MVVM (Model-View-ViewModel) + Repository Pattern
*   **Асинхронность:** Kotlin Coroutines, Flow, StateFlow
*   **Навигация:** Navigation Compose (с поддержкой Deep Links)
*   **Внедрение зависимостей (DI):** Manual DI (через `AppContainer`)
*   **Хранение данных:** `SharedPreferences` (сериализация в JSON для эмуляции БД)
*   **Архитектура UI:** Unidirectional Data Flow (UDF), использование `sealed interface` для состояний экранов (Loading, Success, Error, Empty).
